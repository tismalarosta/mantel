# Support

Mantel is a personal project, shared as is. There is no promised response time, but every issue gets read.

Report a bug or ask for a feature in this repository's [issues](../../issues). Please include your Mantel version (Settings, About), your macOS version and the steps to reproduce.

Mantel is a fork of [Vorssaint](https://github.com/vorssaint/vorssaint-utils). Please don't report Mantel problems to Vorssaint or to the other projects Mantel builds on, unless you can reproduce them in their own app.

For security issues, see [SECURITY.md](SECURITY.md).
